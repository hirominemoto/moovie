# もーバー（claude.ai トークンバー）

claude.ai のチャット画面の上に、うしと月のバーを出す Chrome / Edge の拡張機能。

- **うし（このチャット）**: いまの会話のトークン量が、上限の何%か。うしが右へ歩いていって、50%・80%・95% で色が変わり、ふきだしでしゃべる。汗をかいて、最後は目を回す
- **月（使用上限）**: claude.ai の設定画面「使用量」と同じ、5時間枠と1週間の使用率。多く使っているほうに合わせて月が満ちていく

うしをクリックすると鳴く。月をクリックすると、次にリセットされる時刻を教えてくれる。

## 入れ方

1. zip を解凍する（`claude-moo-bar` というフォルダができる）。このフォルダは消さずにとっておく
2. Chrome のアドレスバーに `chrome://extensions` と入れて開く（Edge なら `edge://extensions`）
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押して、解凍した `claude-moo-bar` フォルダを選ぶ
5. claude.ai を開く（開いていたら再読み込み）

新しい版にするときは、同じ場所の `claude-moo-bar` フォルダを新しい中身で上書きしてから、`chrome://extensions` のもーバーの欄にある「↻」（再読み込み）を押して、claude.ai も再読み込みする。

## 使い方

- バーの左はしの点々をドラッグすると、好きな場所に動かせる。ダブルクリックで真ん中にもどる
- 右の「－」で小さくなる（うしと月の％だけ）。小さいバーを押すと元にもどる
- スライダーのボタンで設定がひらく
  - **このチャットの上限**: 20万 / 50万 / 100万トークン。プランやモデルで変わるので、合うものを選ぶ
  - **上乗せするトークン**: 数えきれないぶんを足したいときに
  - **プロジェクトの資料も数える**: プロジェクトの中のチャットで、資料のぶんも足す
  - **使用上限を表示する**: 月のバーのオン・オフ

## 数字について（正直なところ）

- **うしの数字は推定**。claude.ai は会話のトークン数を外に出していないので、claude.ai が画面に会話を出すときに読んでいる会話データの文字を数えて、「日本語は1文字1トークン強、英語は3〜4文字で1トークン」くらいで見積もっている
  - 数えるもの: いま表示している会話（編集して枝分かれしたときは、表示しているほうだけ）、添付したテキストの中身、プロジェクトの資料
  - 画像やPDFは中身の文字が取れないので、1つ1,500トークンとして数えている
  - 数えないもの: システムの指示、考えている途中の文章（次の返事には持ち越されないため）
  - 会話データが読めないときは、画面に出ている文字で数える
- **月の数字と会話データは非公式な読み方**。claude.ai の画面が使っているのと同じところから読んでいるけれど、公式に用意された方法ではない。claude.ai の作りが変わると読めなくなることがあって、そのときは「—」になったり、画面の文字で数えたりする（マウスを乗せると理由が出る）

## うまく動かないとき

設定をひらくと、いちばん下に「しくみの状態」が出る。どこまで読めているか（会話データ、画面の文字、使用上限）がわかるので、ここのスクショがあれば直しやすい。

## 中で何をしているか

- 動くのは `https://claude.ai/` のページの中だけ。ほかのサイトでは何もしない
- 外部のサーバーには何も送らない。通信するのは claude.ai 自身だけ。使用量は3分に1回とメッセージを送ったとき、会話データはチャットをひらいたときと返事が書き終わったとき（最短8秒おき）に読む
- 設定とバーの位置は、ブラウザの claude.ai 用の保存場所（localStorage）に覚えておく
